# SPARK Hub Website

This repository contains the source code of the [SPARK Hub website](http://spark-hub-website.vercel.app/), an innovation-centric student organization, envisioning to lead the Innovation Center for the youth in Western Visayas. This website serves as a platform to get to know SPARK Hub by its mission and vision, its officers, and its initiatives. For more details about the organization, simply visit the website or our Facebook page: [WVSU - SPARK Hub](https://www.facebook.com/WVSUSparkHub).
